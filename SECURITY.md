# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability or unexpected smart contract interaction issue, please do NOT open a public GitHub issue.

Please report vulnerabilities directly to:
- **Email:** `luca.celebrano1@gmail.com`
- **Telegram:** [Arbitrage Inception Telegram](https://t.me/ArbitrageInception)

### What to Include
- Detailed description of the potential vulnerability
- Steps to reproduce or simulation transaction payload
- Potential impact and affected vaults or pools
- Suggested remediation (if any)

We acknowledge security disclosures within 48 hours and coordinate fixes before public release.

## Scope
- Vault management and zap route aggregator interface in this repository
- Slippage calculation and client-side transaction parameters

## Out of Scope
- Underlying third-party liquidity and lending protocols (KyberSwap, Venus Protocol, Lista DAO, pSTAKE, Stader) — report directly to respective teams
