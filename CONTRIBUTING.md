# Contributing to Arbitrage Inception Earn & Vaults

We welcome open-source contributions to expand multi-protocol DeFi vault integrations and optimize swap routes on BNB Smart Chain.

## How to Contribute
1. Fork the repository.
2. Create a feature branch: `git checkout -b feat/your-feature`.
3. Ensure the project builds cleanly without errors: `npm run build`.
4. Check linting: `npm run lint`.
5. Submit a Pull Request against `main` with a clear explanation of changes.
